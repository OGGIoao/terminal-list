# pycheat 使用详细说明

> 个人终端工具箱主入口 · 离线·零依赖·即查即用 + 本地 ollama 语义检索
> 维护：小o / 老Z · 最后更新 2026-08-27

---

## 0. 一句话定位

`pycheat`（短名 `c`）是一个**说人话就能查命令**的终端速查工具。你不用死记命令名，直接描述你想干的事，它把最相关的命令卡弹给你——带「作用 / 用法 / 示例 / 踩坑」四段彩色卡面，还能一键复制示例。

- 离线就能用（本地匹配，零联网依赖）
- 装了 ollama 会自动叠加**语义检索**（同义/近义也能命中）
- 越用越懂你（自学习别名 + 间隔复习）
- 敲错命令时主动给你提示

## 1. 安装与配置（当前本机已装好）

整个工具零额外 Python 依赖（只用标准库 + 系统 `pbcopy`/`clip`）。链路如下：

| 环节 | 位置 | 作用 |
|---|---|---|
| 主程序 | `~/terminal-toolbox/pycheat.py` | 全部逻辑，已设可执行位 |
| 全局命令 | `~/bin/pycheat`（软链 → 上面） | 任意目录敲 `pycheat` 都行 |
| 短名别名 | `~/.cheat.zsh` → `~/.zshrc` 第 8 行 `source` | `alias c='pycheat'` |
| 数据源 | `~/.config/cheat/cheatsheet.md` | 48 张命令卡（含 8 张 ollama），所见即所得 |
| 学习库 | `~/.config/cheat/.pycheat_learned.json` | 自学习说法库 |
| 复习库 | `~/.config/cheat/.pycheat_strength.json` | 每张卡的查看/遗忘曲线 |
| 向量缓存 | `~/.config/cheat/.pycheat_vectors.json` | ollama 卡片向量，按内容 hash 缓存 |

**重装 / 换机器只需三步：**
```bash
# 1. 把仓库 pycheat.py 放到 ~/terminal-toolbox/
# 2. 建软链（让 pycheat 全局可敲）
ln -s ~/terminal-toolbox/pycheat.py ~/bin/pycheat
chmod +x ~/terminal-toolbox/pycheat.py
# 3. 在 ~/.zshrc 里加一行（已加则忽略）
echo 'source ~/.cheat.zsh' >> ~/.zshrc
```

> Windows 用户：数据源里每张卡都带了「Windows 对照」字段（如 `systeminfo`/`wmic`/`typeperf`），跨平台照样查；复制用系统 `clip`。

## 2. 日常怎么用（4 个最常用动作）

### 动作 A：进开场屏（无参数）
```bash
c
```
直接回车进开场屏，会列出：
- **📌 你可能关心的指令**——按「置顶 + 最近查看」混合排序的推荐卡
- **↻ 该复习的**——被判定「快忘了」的卡（看过 <3 次或 >7 天没看）
- **🧠 语义检索已启用** 提示（ollama 在跑时才出现）

开场屏里输入编号或关键词可继续看卡、回退、前进（交互式浏览）。

### 动作 B：人话搜索（最常用）
```bash
c 哪个进程吃内存
c 强制结束没响应的程序
c git 提交改动
c 看系统是什么版本
```
- 支持**中文描述**、**拼音**（如 `neicun`）、**命令名**（`c top`）、**英文**混合
- 返回按「本地匹配分 + 语义温和加成（融合排序）」排序的彩色卡面
- 清晰命中永远压过语义噪声（实测：`强制结束没响应` → `kill` 顶到 #1）

### 动作 C：复制示例到剪贴板
```bash
c -c 看内存          # 把最佳匹配的「示例」命令直接复制到剪贴板
c --copy top
```
适合「我就想把这个命令拷走用」的场景，省得手动选。

### 动作 D：列全部命令
```bash
c -l
```
带编号 + 用途，一口气看全库有什么；配合开场屏的浏览模式回退/前进翻看。

## 3. 卡面长什么样（四段彩色）

每张卡固定四段，颜色区分、扫一眼就懂：

| 段 | 颜色 | 内容 |
|---|---|---|
| **作用** | 蓝 | 这条命令解决什么问题（人话） |
| **用法** | 青 | 命令语法 `[选项]` |
| **示例** | 绿 | 可直接抄的实战命令 + 输出说明 |
| **踩坑** | 黄/红 | 新手最容易栽的地方、平台差异 |
| （附）别名 | 灰 | 人话/拼音/英文别名，命中靠它 |
| （附）Windows对照 | 灰 | 同功能 Windows 命令 |
| （附）来源卷 | 灰 | 出自 OS 课的哪一卷 |

> 一条卡写全了，就是一份**迷你教程**，不用再开浏览器。

## 4. 语义检索（ollama，可选增强）

装了本地 ollama 后，`pycheat` 会自动叠加向量语义匹配——**同义/近义也能命中**（如「哪个进程吃 RAM」↔ `top / htop`）。

**机制：**
- 零额外依赖，仅 `urllib` 调本机 `http://localhost:11434/api/embeddings`
- 排序 = **融合排序**：本地匹配分占主导，语义相似度只做温和加成，**绝不覆盖清晰本地命中**
- 嵌入模型默认 `nomic-embed-text`；若本机已拉 `bge-m3`（中文更强）会**自动优先**
- 卡片向量按内容 hash 缓存在 `.pycheat_vectors.json`，首次拉取后增量更新

**三个开关：**
```bash
c 哪个进程吃 RAM            # 自动：ollama 在跑就增强，否则纯离线
pycheat --llm 看系统版本    # 强制语义检索（ollama 不可用则报错退出）
pycheat --no-llm git提交    # 强制离线（即便 ollama 在跑）
```

**把中文区分度拉满（可选）：**
```bash
ollama pull bge-m3          # 约 2GB+，拉到即生效，代码已自动优先，无需改配置
ollama list                 # 确认 bge-m3:latest 在位
```

## 5. 自学习别名 + 间隔复习（越用越懂你）

**自学习**：每次你用「人话」搜并命中某卡，这条「说法 → 命令」会被固化。下次同类说法直接命中，不必重算。
```bash
pycheat --learn            # 查看已学说法 + 命中次数
pycheat --learn show       # 同上
pycheat --learn clear      # 清空学习库
pycheat --forget 看内存    # 忘掉某条说法
```
> 只在「说法不是现成命令名/别名」时才学，命令名本身不进库，避免污染。

**间隔复习**：每张卡记录查看次数与上次时间，开场屏自动挑「快忘了的」提醒你巩固（看过 <3 次或 >7 天没看），从没看过的算新学、不进复习。

## 6. 命令敲错主动提示

在交互 zsh 里敲了一个不存在的命令，`command_not_found_handler` 会调 `pycheat --suggest` 给你相关卡提示：
```
💡 没找到命令 'gti'，但 pycheat 里有相关的：git
   输入 c <名字> 看详情（直接 c 回车进开场屏）
```
（仅交互式 zsh 生效；太短或像路径的尝试不触发，避免误打扰。）

## 7. 自己加命令卡（最该掌握的进阶）

数据源是纯 markdown，**加一张卡 = 文末加一个 `## 命令名` 区块**，存盘后下次 `c` 自动加载，无需改代码。

字段模板（七行，少哪行都不影响加载，但建议写全）：

```markdown
## 你的新命令
- 别名: 人话说法1,人话说法2,拼音
- 作用: 一句话说明解决什么
- 用法: 命令 [选项] 参数
- 示例: `实际命令` → 输出说明
- 踩坑: 最容易错的点 / 平台差异
- Windows对照: 等效的 Windows 命令（没有写 无）
- 来源卷: 你从哪学来的
```

### 现场演示：我们刚加的 `ollama show` 卡

小o 按上面模板，往 `~/.config/cheat/cheatsheet.md` 文末真加了一张卡（这是一张当前缺、且实用的卡），**你敲 `c show` / `c 看模型详情` 现在就能搜到它**：

```markdown
## ollama show
- 别名: 看模型详情,模型参数,模型信息,查模型配置
- 作用: 查看已拉模型的元信息（参数/上下文窗口/license/模板/系统提示），排查"为啥这个模型表现不对"
- 用法: `ollama show <模型名>` ；对话中也可用 `/show`
- 示例: `ollama show bge-m3`              → 看 license / 1024 维向量 / 适用任务
- 示例: `ollama show qwen2.5:0.5b`        → 看参数规模、上下文长度(num_ctx)、模板
- 示例: `ollama show nomic-embed-text`    → 确认它是嵌入模型(dim 768)、不可用于聊天
- 踩坑: `show` 看的是模型卡(moderfile)信息，不含权重本身；想看实际跑起来的占用用 `ollama ps`
- 踩坑: 模型名带标签时要写全，如 `qwen2.5:0.5b`，否则按 latest 解析
- Windows对照: 同
- 来源卷: 工具箱·ollama
- 备注: 本卡为「自己加卡」功能的现场演示示例
```

**一步步就是这么加的：**
1. 打开数据源：`open ~/.config/cheat/cheatsheet.md`（或任意编辑器）
2. 滚到文件最末尾，粘贴上面整段（含 `## ollama show` 标题）
3. ⌘S 存盘 —— **不用重启任何东西**
4. 终端敲 `c 看模型详情` 验证，它会把 `ollama show` 顶上来

要点：
- **别名行是命中关键**——多写人话/拼音，搜得到全靠它（这张特意写了「看模型详情/模型参数/查模型配置」）
- 示例用反引号包裹命令，卡面会高亮
- 想删卡：把整段 `## 名字 …` 删掉存盘即可
- 改完存盘即可，下次 `c` 自动加载

## 8. 常见问题排查

| 现象 | 原因 / 解决 |
|---|---|
| `c` 命令找不到 | `~/bin` 不在 PATH，或软链断了 → 重跑 §1 三步 |
| 敲 `c` 没开场屏 / 直接列一堆 | 旧版 `cheat` 函数残留 → 确认 `~/.zshrc` 已 `source ~/.cheat.zsh`，旧函数已删除 |
| 语义检索没生效 | ollama 没起 → `ollama serve`；模型没拉 → `ollama pull nomic-embed-text` |
| 强制 `--llm` 报错退出 | 模型名对不上 / ollama 未起 → 用 `ollama list` 核对，或改用 `--no-llm` |
| 想彻底离线 | 加 `--no-llm`，或停掉 ollama 即可 |
| 卡面中文乱码 | 终端字体缺字，与工具无关 |
