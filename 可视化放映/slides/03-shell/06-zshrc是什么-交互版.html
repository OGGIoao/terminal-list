.zshrc 到底是什么

场 06 · .zshrc 是什么
~/.zshrc3 行 · 脚本
export NVM_DIR="$HOME/.nvm"# 设变量 [ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"# 加载 nvm [ -s "$NVM_DIR/bash_completion" ] && \. "$NVM_DIR/bash_completion"# 加载补全

不是设置文件

是脚本——每次启动终端从头到尾执行一遍

改完要生效

重开终端，或 source ~/.zshrc

安全敏感

能写它 = 能控制你的终端
